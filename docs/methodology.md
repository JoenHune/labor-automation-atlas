# 研究与证据方法（工作版）
研究日期：2026-09-09。冻结前仍可扩展任务清单，任务数量由流程覆盖和来源决定。

## 数据
主视图取最新已发布完整年度现价增加值；年度、季度现价（美国季度可能为季调年率）、实际增速分别存储和展示，绝不混排。中国按最新公开可识别大类排名；制造业等工业子项只在行业内拆解。“其他行业”规模展示为未拆分汇总，不分配给未公布行业。美国选择 BEA 同一级非重叠行业集合并保留 government 的组成说明。中美仅各国内部排名，不换汇合并。
所有观测包含数据期、频率、计价、单位、发布日期、修订状态、覆盖范围、来源表格/行/列。2021—2025 优先从同一最新修订来源抽取；取不到的观测为空并显示缺口，不能回填过时初值。执行初查和发布前复查都有时间戳与下载哈希。

## 细分行业与显示币种
点击国家页的行业规模柱可展开互斥细分类别，默认选择主视图年份，并提供“人均产值”和“增加值”两种排序。人均产值按同年、同统计范围的现价增加值除以从业人数计算；就业岗位、仅雇员、年末人数和其他统计时点分别标注、分组。分子或分母缺失、范围不匹配时保留空值，不以收入、总产出或跨年就业数替代。历史可比结果需明确切换，使用位置显示资料年份。当前中国多数细分仍缺匹配增加值或就业分母；美国私人细分可比岗位主要限于2021—2022年，政府2021—2024年雇员数可展示，但年度平均处理待核，暂不计算比值。

全站金额可切换为亿元人民币或百万美元，默认换算假设为1美元=6.71元人民币，可编辑并随链接、导出保存。人民币亿元转百万美元为原值×100÷汇率，百万美元转人民币亿元为原值×汇率÷100；每人或每岗位金额使用元或美元。显示换算不改变原始观测、国内排名、就业规模或百分比。原币数值、来源、计算输入和限制可在各行详情与导出中核对。

详细取数与边界见[中国细分资料](https://github.com/JoenHune/labor-automation-atlas/blob/main/research/cn/subindustry-productivity.md)、[美国细分资料](https://github.com/JoenHune/labor-automation-atlas/blob/main/research/us/subindustry-productivity-methods.md)及[本次独立复核](https://github.com/JoenHune/labor-automation-atlas/blob/main/research/reviews/preview-10-productivity-and-currency-review.md)。

## 任务覆盖
每个行业先列主要子行业与场景。流程路径：准备/接收 → 作业 → 交接 → 检测 → 异常处置 → 返工 → 清洁维护 → 交付；流程可分支回流。职业职责路径：以官方职业标准、职业信息数据库和岗位规范收集活动，映射回流程。职业名称只作为发现任务的索引。
每项任务用“动作＋对象＋完成条件”命名，需可独立描述、验收和核算。拆分不可验收的复合任务；合并只在执行条件、输出、设备适配和证据一致时进行，跨行业重复劳动保留独立国家/行业语境。
每个场景记录 source-backed / proposed / gap 状态。流程无任务、任务无来源、职责无映射都会进入覆盖审查。公开资料不能证明穷尽真实世界所有劳动，首版“全部”仅指经公开资料双路径审查并冻结的任务清单，其明确排除项和未知场景随版公布。

## 逐项检索
每项任务都有三个独立搜索方向及时间戳：人工流程/职责；自动化方案/部署；失败、退出、未采用或适用限制。记录查询词、国家范围、实际读取来源、支持/反驳的结论、无结果及访问失败。不得用共用行业案例替代任务级检索。
比较传统机械、专机、机器人、辅助工具及必要数字流程，区分可获得方案与已证明适用。没有案例不能推出技术不可行；职业职责不能给出工时或人工占比。
每个任务保留人力参数缺口、残留劳动和异常处理。成功反例须与障碍发生于相同或明确差异的条件；国家外资料可作为明确标记的技术背景，不能作为本国商业部署结论。

## 证据与判断
结论类型为直接事实、可复算计算、研究判断、待验证假设。来源定位支持网页标题/小节/段落、表格行列、PDF页码与原文短摘录。部署证据单独标明厂商自报、实验室、试点、持续商业运行；厂商宣传中的“商业”不自动升级为持续运行。每个数字既有数值字段也有 claim/evidence 关联。
技术、经济、采用障碍可以并存；障碍描述必须包含具体对象、环境、质量验收、节拍、异常率等适用条件。有来源的事实和研究者推断分开呈现。
独立复核者检查来源是否实际支持结论、来源国家是否一致、日期、样本选择、负面检索、反例和计算；冻结研究版本只包含已审查记录。评论经审校形成新的 claim 与研究版本，不能直接覆盖事实。

## 增量现金流
部署初始投入 I = 设备 + 工装 + 集成 + 安全改造 + 场地改造 + 培训 + 调试停产 + 首期营运资金。
每期增量现金流 CF = 可兑现人工成本节省 + 有需求且解除瓶颈的增量毛利 + 已证实损耗节省 − 残留新增人工 − 维护耗材 − 软件/服务 − 能源差额 − 异常/停机净损失 − 其他增量现金支出。
人工节省只计算可取消的加班、外包、自然减员或确实减少的付薪工时，不能把理论操作时间全额货币化。已在产量差或残留人工中计入的停机/异常不重复扣减。
NPV = −I + Σ CF_t/(1+r)^t。回收期只在完整时间现金流与明确时点下计算，不用行业均价替代实际报价。
缺少关键参数时不给回收期：显示缺失字段；允许在用户明示的期限/成本假设下计算盈亏门槛，并标为假设情景，货币和国家保持一致。
