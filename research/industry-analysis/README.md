# 行业分析研究包

本轮围绕当前中国电子设备分支回答：官方资料探索到了哪里、地区结构是什么、上市公司财报怎样补充认知。全部 211 个既有投入产出产品另补增加值四分项；本轮没有恢复人工任务或自动化回报研究。

## 入口

- `plan.md`：用户目标、范围、验收边界。
- `methodology.md`：生成网站“行业分析”页的正文。
- `distribution/data.json`：211 个产品增加值与劳动报酬、生产税净额、折旧、营业盈余；按代码求和复算。
- `official/`：全国统计资料审计、电子行业经营及最新进展、异常登记和独立读表。
- `regions/`：31 省统一规上表、重点地方公报、北京/重庆产品部门、2025 地方进展、逐省资料覆盖。
- `companies/`：13 家目的样本、原值、分部、计算、2025 年报与 2026 半年报来源和恢复脚本。
- `deep-reading/`：继续实读的全国附表、地方年鉴内表与公司财务附注；读取范围、原观测和同编号修订单独保存。
- `dataset.json`：从上述四组输入生成的图表分析数据，不是另行手工维护的数值。

## 再生成与下载

`npm run generate` 从各模块已核数据生成统一研究资料、网站页面和三个公开导出文件：

- `exports/industry-analysis.json`：当前图表所用比较表、分配、结论、覆盖和证据。
- `exports/industry-analysis-research.json`：上述视图数据以及完整全国、地区观测和全部公司原值、分部、派生计算、样本与来源。
- `exports/industry-reading-log.json`：实际读页、读表边界及补读修订，包含未读和仅定位部分的说明。

这些导出存在有意重复，不能把同一观测重复求和。各研究模块的构建/验证脚本另见本目录文件；原始下载缓存不一定提交，公开来源地址与 SHA-256 用于恢复原件。数据源发生变化时应核对新旧版本，不能覆盖原哈希后仍宣称同一研究版本。

## 保留的边界

国家/地方官方资料尚未穷尽；覆盖登记对本轮具体入口负责。企业样本不能代表全国总体，其业务、员工、海外范围、外包及并购影响均保留。普查行业与投入产出产品不同，不把收入或人均收入改称增加值，也不以财报毛利代替增加值。

产品分配允许负值和大于 100% 的分项比例。研发表父子残差、月度来源异常、地方公报原件未取得等问题单独记录，不强平或猜测填数。网站批注不是研究事实，后续证据须经审校与版本更新。
