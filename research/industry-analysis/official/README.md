# 全国官方资料与C39分析

核查日 2026-09-14。仅宏观结构和经营研究；没有恢复任务、机器人或回报研究。

- `analysis.md`：分析正文、方法、异常和后续路径。
- `analysis.json`：216条事实/计算观测，逐项记录资料期、单位、范围、发布/修订状态、原件、SHA-256及单元格定位；C39父项与9中类分开，含2024年鉴14项经营/用工观测。
- `panel-data.json`：通过仓库 `validateIndustryAnalysis` 强校验的24个来源、5个比较表、7条结论和13条覆盖登记；不是另一套研究事实。
- `coverage-matrix.json`：按资料入口区分取得、无指标、待取和未查；不声称所有国家/地方资料穷尽。
- `anomalies.json`：2026东北负营收、研发父子残差、不同批次金额/可比同比差异，均保留而非改写。
- `source-manifest.json`：20份实际来源及哈希，含复用并重读的前轮年鉴原图；panel另复用4份前轮实际原件证明覆盖状态。IO一项为本次独立读取的可见DOM，不冒称原始Excel。
- `validation.json`：哈希、财务父子计算、IO九产品45个原值独立复核、研发未平衡差额。
- `originals/`：原始HTML、JPG、PDF；同名TXT是派生阅读/OCR文件，裁片只作目视复核辅助，不能替代原件。

从仓库根目录复算：

```sh
python3 research/industry-analysis/official/build_analysis.py
python3 research/industry-analysis/official/build_panel.py
```

脚本不联网。财务与研发图片的值是逐行目视转录，OCR仅协助找行。不存在全部图片自动OCR后直接作为事实入库的流程。整体检查只覆盖本次明确字段和来源，不能证明全站全部资料已研究完。
