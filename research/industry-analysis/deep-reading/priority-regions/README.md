# 七地地方年鉴：第二轮实读包

检查日期：2026-09-14。范围：北京、上海、江苏、浙江、广东、重庆、四川的 C39；七地 2024/2025 两版工业内表，相关就业目标表、统计范围说明、浙江五经普恢复及广东最新一期。

- `analysis.md`：研究增量、数据含义与尚未完成的边界。
- `observations.json`：115 条原值观测。包含两版披露，不能直接拼成可比增速；额外 `regionId/metric/edition` 明确地区、指标和来源版次。
- `panel-data.json`：31 个来源，7 个单地区营收表、4 项发现、8 条新增覆盖记录。每个表只展示一个地区，未新建七地混合口径排行榜。
- `read-log.json`：31 条实读记录：14 张工业目标表、10 张就业目标表、5 份说明、2 份公报。列出未读范围、逐次访问失败和后续缺口。
- `amendments.json`：11 条完整同 ID 修订建议；3 张比较表恢复浙江空值，8 条覆盖更新。未修改冻结的上一轮模块。
- `sources.json`、`source-manifest.json`：原件 URL、数据期、发布或版次说明、SHA-256；原件保存在 `originals/`，目标提取在 `extracted/`。
- `fetch-log.jsonl`：公开来源下载成功/失败记录。浏览器成功访问另由目标 DOM/文本保存，并在实读日志中说明。
- `build.py`：在本目录生成数据包。读取冻结上一轮数据以形成同 ID amendments；不写其他目录。

重要边界：收入不是增加值；平均用工不是期末从业；非私营总体不是规上全体；年鉴版次不是数据年度；取得载体不等于已读完全书。空白与不匹配指标未用于填造人均增加值。

江苏直连 403 后通过浏览器读取，`js-2025-11-6-selected-dom.json` / `js-2024-11-6-selected-dom.json` 保存完整目标表头及 C39 行。早期整页 DOM 返回存在截断，仅作访问诊断，未作为最终取值原件。广东光盘仅解出所需表和说明；重庆整本 PDF 仅审读日志所列页表。

验证记录见 `validation.json`。另有 70 个结构化原表单元格与输出的逐值比对，记录在 `value-checks.json`。独立复核意见由父流程汇总后决定整合与发布。
