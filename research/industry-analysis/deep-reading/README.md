# 继续补读：从入口推进到原表与附注

继续执行用户 2026-09-14 的“继续努力”。沿用宏观分析范围，人工任务、自动化方案、回报与讨论后台暂停。

- national：国家普查控股、新产品和知识产权附表；工信部 2024 年年度统计主要经济指标原表。
- priority-regions：北京、上海、江苏、浙江、广东、重庆、四川的地方年鉴/普查目标内表。
- other-regions：其余 24 地的地方年鉴/普查目标内表及逐入口失败记录。
- company-notes：既有 13 公司、26 份报告的管理层讨论和存货、应收、现金、补助、在建工程、并购/分部、外包/员工等相关附注。

实际读页、读行列写入各模块 read-log.json；仅定位、仅下载、候选页与未读部分单列。原事实写入 observations.json，当前展示写入 panel-data.json，旧记录修正写入 amendments.json。旧模块冻结不覆盖；生成时以同编号替换当前视图，并在完整研究导出保留修订理由与旧研究原值。

本轮不以下载数量或页数等同研究完成度，不宣称读完所有地方年鉴或财报。发布前由根代理交叉检查来源、原值、口径和新判断；版本与发布证据见 verification.md。
